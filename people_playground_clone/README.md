# People Playground Clone (Python + pygame + pymunk)

Полноценная 2D sandbox-игра с физикой, ragdoll-персонажами, оружием, частицами, огнём, сохранениями, JSON-картами и UI.

## Возможности
- Главное меню с анимациями и hover-эффектами.
- Камера WASD + zoom колёсиком.
- Спавн-меню с категориями и объектами.
- Ragdoll-люди (голова, тело, руки, ноги, суставы).
- Материалы: дерево, металл, стекло, камень, резина, плоть.
- Урон от столкновений и снарядов.
- Частицы крови (отключаемо), огонь, дымовые/искровые эффекты.
- Объекты: ящики, блоки, кирпичи, колёса, двери, платформы, лампы, шипы.
- Оружие: пистолет, винтовка, дробовик.
- Drag & drop мышью, выделение объекта, поворот, freeze, удаление.
- Сохранение/загрузка сцены в слоты.
- Карты из JSON: sandbox, laboratory, industrial, test_room.

## Установка зависимостей
```bash
pip install pygame pymunk
```

## Запуск
```bash
cd people_playground_clone
python main.py
```

## Управление
- **ЛКМ** — выбрать/перетаскивать объект
- **ПКМ** — выстрел выбранным оружием
- **Колесо** — zoom
- **WASD** — камера
- **Delete** — удалить выделенный объект
- **R** — повернуть объект
- **F** — заморозить/разморозить
- **G** — отключить/включить влияние гравитации
- **E** — взаимодействие (поджечь, где применимо)
- **Ctrl+S** — сохранить (slot1)
- **Ctrl+L** — загрузить (slot1)
- **Tab** — показать/скрыть spawn panel
- **Space** — пауза физики
- **Esc** — меню

## Как добавить новые предметы
1. Открой `core/ui.py` и добавь название предмета в `spawn_items` нужной категории.
2. Открой `core/engine.py`, метод `spawn_object`, добавь ветку `elif` для нового предмета.
3. Используй `entities/item.py` для физического объекта или создай новый класс в `entities/`.
4. При необходимости добавь новый материал в `config.py -> MATERIALS`.

## Как добавить новые карты
1. Создай новый JSON в `data/maps/`.
2. Формат:
```json
{
  "name": "my_map",
  "objects": [
    {"id": "Human", "pos": [0, 220]},
    {"id": "Wood Crate", "pos": [90, 300]}
  ]
}
```
3. Загрузку карты можно вызвать из `engine.load_map("my_map")`.

## Сборка в .exe (PyInstaller)
```bash
pip install pyinstaller
cd people_playground_clone
pyinstaller --noconfirm --onefile --windowed --name "PeoplePlaygroundClone" main.py
```
Исполняемый файл будет в `dist/PeoplePlaygroundClone.exe`.

## Примечания
- Папки `assets/sounds`, `assets/images`, `assets/fonts` готовы для подключения реального контента.
- Аудио-система поддерживает подключение звуков через `core/audio.py`.
